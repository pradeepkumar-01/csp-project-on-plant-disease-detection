Model Architecture

  • Input Layer: Leaf image (RGB, 224×224)
  • Convolutional Layers: Extract textures and leaf spots
  • Pooling Layers: Reduce spatial size
  • Residual Connections: Preserve feature details
  • Fully Connected Layers: Classify plant type and disease
  • Output Layer: 38 plant–disease classes
